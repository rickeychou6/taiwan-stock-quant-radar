# AI 股票全方位決策系統

這是一個 Next.js SaaS 架構的股票與商業雷達網站，包含台股分析、自選股、持股管理、市場總覽、AI 模擬交易，以及電商銷售雷達。

> 風險提醒：本系統僅供研究與輔助判斷，不構成投資建議。股票與商品銷售判斷都可能因資料延遲、來源限制、突發消息與市場情緒而失準，請自行控管風險。

## 主要功能

- 股票 Dashboard：股名/股號搜尋、AI 分數、買賣建議、支撐壓力、停損、目標價、K 線與指標摘要。
- 個股推薦：依技術面、籌碼面、風險報酬比與可靠度排序，找出較適合觀察或進場的股票。
- 自選股：記錄個股、追蹤買賣點警示與分析摘要。
- 持股管理：輸入成本與持股，顯示續抱、減碼、停利或停損參考。
- 市場總覽：台股、美股、期貨、日韓指數與重要市場指標。
- AI 模擬交易：以虛擬資金紀錄選股、買進、賣出與交易歷史。
- 電商銷售雷達：使用公開商城資料做熱銷排序、利潤估算、分類排行、生活小物統計、低售服高回購商品、季節因素熱賣商品、低成本高毛利商品、AI 選品推薦、下月/下季商品機會預估。

## 電商雷達資料說明

電商雷達目前使用 PChome 24h 公開搜尋 JSON 作為真實公開資料來源：

- 取得商品名稱、價格、原價、圖片、商品頁、搜尋結果數與熱銷排序訊號。
- 系統會盡量嘗試 Shopee 蝦皮公開搜尋端點；若來源要求登入 Cookie、驗證或被反爬，會在資料來源狀態中標示失敗，不用假資料補值。
- 拼多多匿名網頁目前沒有穩定公開 JSON 商品/價格資料；系統會嘗試連線並標示來源狀態，但不硬爬動態頁面，避免抓到錯誤資料。
- PChome 公開資料沒有提供真實銷售件數，因此「銷售量最大」以熱銷排序、搜尋結果規模、折扣、價格帶與分類熱度推估，不會假造實際銷售量。
- 成本與利潤為估算模型，可在頁面調整：平台抽成、金流費、物流成本、廣告費、退貨準備金。
- 商品分類會依關鍵字與商品名稱自動歸類，例如 3C、小家電、美妝保養、健康保健、寵物用品、母嬰玩具、運動戶外、居家生活、食品飲料、服飾鞋包、車用百貨、辦公文具等。
- 生活小物類會獨立統計，例如收納、掛勾、置物架、廚房小物、浴室收納、保溫杯、小夜燈、防塵罩、密封袋與桌面收納。生活小物分會把低單價、低進貨成本、低售服、毛利率、淨利率、熱銷排序與回購屬性一起納入。
- 低價小體積生活小物推薦會優先挑售價低、估成本低、回購率高、非大型且估淨利為正的商品，避免大型品造成倉儲、物流與退貨壓力。
- AI 選品推薦會依照季節性、回購率、低成本、毛利率、尺寸等級與售後負擔一起評分，並輸出「優先測品 / 可小量測試 / 等待比價 / 暫不建議」。
- 低售服高回購分會把回購分、售服負擔、熱銷排序、淨利率與高單價風險一起納入。保健食品、寵物消耗品、洗衣精、衛生紙、零食飲品、辦公耗材等會有較高回購權重；高單價或需保固維修的品項會降低低售服分。
- 季節熱賣分會依目前月份、品類季節字、熱銷排序、折扣與成本效率推估，例如夏季、防曬、清淨除濕、開學、中秋、年節與換季需求。
- 低成本高毛利分會依毛利率、淨利率、單品售價門檻、熱銷分與售服負擔推估，用來尋找小資金可測、成本壓力較低的商品。
- 下月與下季預估使用熱銷排序、搜尋池規模、價格、折扣、淨利率、分類季節性與風險因子推估。

## 本機啟動

```bash
cd ai-stock-decision-saas
npm install
npm run dev
```

預設網址：

```text
http://localhost:3000
```

驗證指令：

```bash
npm run typecheck
npm run build
npm run start
```

## 重要頁面

- `/dashboard`：股票分析
- `/recommendations`：個股推薦
- `/ecommerce-radar`：電商銷售雷達
- `/auto-trader`：AI 模擬交易
- `/radars`：雷達入口
- `/watchlist`：自選股
- `/portfolio`：持股管理
- `/market`：市場總覽
- `/admin`：管理後台

## API

- `/api/ecommerce/radar`：電商雷達資料
- `/api/analysis/[symbol]`：個股分析
- `/api/recommendations`：個股推薦
- `/api/market/overview`：市場總覽
- `/api/auto-trader/state`：AI 模擬交易狀態
